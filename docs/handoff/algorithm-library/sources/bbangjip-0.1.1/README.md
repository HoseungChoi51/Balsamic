# 단일 오븐 주문 순서의 총 픽업 지연 최소화

고정된 주문 8개의 굽기 순서를 선택하여 총 픽업 지연시간을 최소화한다. 단일 오븐에서 중단이나 유휴시간 없이 처리하며, 조기 완료에는 보상이나 벌점이 없다.

주문 8개를 단일 오븐에서 처리하는 순열을 설계한다. 시작 시각은 자정 이후 360 min이며, 모든 완료·픽업 시각은 이 시작을 원점으로 하는 분 단위로 비교한다. 주문별 굽는 시간과 픽업 시각은 고정 입력이다.

첫 주문을 즉시 시작하고 각 주문이 끝나면 다음 주문을 즉시 시작한다. 중단, 분할, 동시 굽기, 취소, 다른 오븐 사용은 허용하지 않는다. 별도의 예열·교체·냉각·포장 시간이나 작업 가능 시각, 선후관계는 포함하지 않는다.

순서대로 굽는 시간을 누적하여 완료 시각을 구하고, 주문마다 완료 시각에서 픽업 시각을 뺀 값과 영 중 큰 값을 지연으로 계산한 뒤 합산한다. 픽업 시각은 실행 가능성 제약이 아니다. 총 지연이 같은 순서는 동등하며, 최종 완료 시각 단축이나 신선도는 별도 목적이 아니다. 최종 순서와 주문별 시작·완료·픽업·지연을 기록한다. 기준 순서는 ["식빵", "바게트", "크루아상", "케이크", "머핀", "쿠키", "타르트", "베이글"]의 나열 순서이며 동일한 규칙으로 비교한다.

## Implementation (v0.1.1)

`objective.objective(problem, candidate)` returns the scalar total tardiness;
`objective.schedule(problem, candidate)` returns the full serial schedule with
relative `start`, `completion`, `pickup`, `tardiness` and separately labeled wall
minutes. The installed evaluator emits these records in `Evaluation.metadata`,
including a separately evaluated original-order `baseline`.

`subset_dp_scheduling` implements H02 only: last-job subset DP with ascending
last-index ties, reconstruction, O(n 2^n) time and O(2^n) space. It uses declared
public quantities, not evaluator calls, during DP. The optimizer_v1 adapter emits
one optimum candidate then finishes after observation. JSON byte checkpoints
preserve ready, outstanding and finished phases; inspection reports the exact
bound. A plain-function wrapper supports the generated local harness.

The charter catalog has eight named order slots; smaller synthetic tests use a
prefix of that catalog. Processing/pickup inputs retain the generated schema.
Numeric integral floats are accepted as indices (the framework uses float arrays);
fractional indices, duplicates, missing indices, strings and booleans are rejected.
No H01 or H03 methods are registered. Dependencies: NumPy 2.5.3; framework imports
are confined to the adapter. Balsamic supplies its own plugin host.

## Running

```bash
pip install -e ".[test]"        # or: uv sync --extra test
pytest                          # the data, the objective and every method
python -m single_oven_total_tardiness.compare --seconds 10 --seeds 2
```

`compare` runs every method on every instance and prints the runs ranked by the objective's direction (minimize),
with each run's time and evaluations. A method marked `@deterministic` runs once.
