# Invariants of L6

The rows of the [invariant register](../invariants.md) that roadmap part L6 added ([readiness](../readiness/L6.md)). Same columns and rules as the register; ids `INV-L6-<n>`.

| ID | Guarantee | State | Where | Pinned by | Closed by |
|---|---|---|---|---|---|
| INV-L6-1 | A problem library's method bound or run on a task whose problem that package does not provide records one open `library_split` per method (its library, package, the problems and campaigns that need it) and tells each campaign's lead once; the method list shows the split as the method's next step | code | `agents/library_split.py` `needed()`, `noticed()`; `implementations/builtin.py` `bind()`; `campaigns/commands.py` (trial.create); `campaigns/method_catalog.py` `catalog()` | `tests/test_library_split.py::test_binding_a_problem_librarys_method_on_another_problem_records_a_split_and_tells_the_lead_once` | |
| INV-L6-2 | A split workspace builds one needed split: it starts from the problem library's latest version, and its ticket asks for a method library `libraries/<library>-methods/` with the split's methods and no problem, and the problem library's next version without them that depends on it | code | `agents/development.py` `split_of()`, `split_library()`, `create()`; `agents/development_ticket.py` `split_lines()` | `tests/test_library_split.py::test_a_split_workspace_starts_from_the_problem_library_and_asks_for_both_libraries` | |
| INV-L6-3 | A split delivery is installed as one step or not at all: it holds exactly the two libraries; the method library is validated first and provides every split method and no problem, takes over no other method of the problem library, and its moved methods pass and replay their recorded runs; the problem library depends on it and is validated with it importable; a moved method counts as kept; both are committed, pinned, synced, tagged and recorded together, and the split is done | code | `agents/library_install.py` `Installer.plan()`, `_validate_split()`, `_keeps()`, `install()`; `agents/library_split.py` `check()`, `takeovers()`; `agents/library_validation.py` `run(dependencies=)` | `tests/test_library_split.py::test_a_split_installs_both_libraries_at_once_and_the_method_moves`, `tests/test_library_split.py::test_a_method_library_that_takes_over_a_method_the_split_does_not_name_is_refused`, `tests/test_library_split.py::test_a_problem_library_that_does_not_depend_on_the_method_library_is_refused`, `tests/test_library_split.py::test_a_split_delivering_one_library_is_refused` | |
