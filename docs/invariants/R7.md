# Invariants of R7

The rows of the [invariant register](../invariants.md) that roadmap part R7 added ([readiness](../readiness/R7.md)). Same columns and rules as the register; ids `INV-R7-<n>`.

| ID | Guarantee | State | Where | Pinned by | Closed by |

| INV-R7-1 | A message sent with a mandate grants it to the request the message opens (as `request_root()` gives it for that run, or a page agent's `desk_root`): Answer and Explore at once, Screen and Run the campaign as the researcher's resolved decision whose compute part is a consent for that request, so the work starts without a card. That consent is request-only: it pays for the work of the request it was granted with and never for another request's, whether or not it names proposals (Hoseung, 27 October 2026); an agent's approved card keeps decision 4's rule (INV-01).
