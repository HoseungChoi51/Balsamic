# Invariants of L4

The rows of the [invariant register](../invariants.md) that roadmap part L4 added ([readiness](../readiness/L4.md)). Same columns and rules as the register; ids `INV-L4-<n>`.

| ID | Guarantee | State | Where | Pinned by | Closed by |
|---|---|---|---|---|---|
| INV-L4-1 | Tests accumulate: a new version of an installed library is validated outside the box against every earlier version's tests it does not hold unchanged (at `/earlier`, never in the coder's copy) and every earlier workspace's protected tests on that library; a failing earlier test refuses the method it names, or the library when it names none, and one naming a method the version removed does not count | code | `agents/library_validation.py` `earlier_tests()`, `earlier_protected()`, `run()`, `verdict()`; `agents/library_install.py` `Installer._validate()` | `tests/test_library_reproduce.py::test_an_earlier_versions_test_of_a_kept_method_refuses_it_and_one_of_a_removed_method_does_not_count`, `tests/test_library_reproduce.py::test_the_host_gathers_earlier_tests_and_recorded_runs`, `tests/test_library_reproduce.py::test_protected_tests_of_earlier_workspaces_on_the_library_stay_with_it` | |
| INV-L4-2 | Kept methods and problems reproduce their recorded runs (decision 25): for each method and problem a new version keeps, up to 3 recorded runs are replayed for their first 8 evaluations; a method fed the recorded results must propose the recorded candidates, or it is refused naming the run and the evaluation; a problem must evaluate them to the recorded objectives (relative 1e-9), or the library is refused | code | `agents/library_validation.py` `recorded_runs()`, `_replays()`, `verdict()`, `reproduced()`; `agents/library_install.py` `Installer._validate()`, `kept_text()` | `tests/test_library_reproduce.py::test_an_unchanged_method_and_problem_reproduce_their_recorded_run`, `tests/test_library_reproduce.py::test_a_kept_method_whose_proposals_changed_is_refused_naming_the_run_and_the_evaluation`, `tests/test_library_reproduce.py::test_a_kept_problem_whose_objective_changed_refuses_the_library`, `tests/test_library_reproduce.py::test_an_install_whose_kept_method_does_not_reproduce_a_run_another_campaign_made_is_refused` | |
