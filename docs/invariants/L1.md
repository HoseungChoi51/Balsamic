# Invariants of L1

The rows of the [invariant register](../invariants.md) that roadmap part L1 added ([readiness](../readiness/L1.md)). Same columns and rules as the register; ids `INV-L1-<n>`.

| ID | Guarantee | State | Where | Pinned by | Closed by |
|---|---|---|---|---|---|
| INV-L1-1 | An install never takes away what a campaign of the lab uses: a method or problem the installed version of the library provides that the new version leaves out, or a method it keeps that fails validation outside the box, refuses the install before uv runs when any campaign ran the method, has a proposal bound to it or has a task on the problem (decision 25).
