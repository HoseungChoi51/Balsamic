# T4 — Do the operator and the moderator still need their own sessions?

State: implemented and tested (PR #91, 2026-10-28); the comparison on Centinels, and with it ADR 0010's result per page
agent, is Hoseung's.

## What was wrong

Layer: prompt. Every page request from the lead is a hand-off to a standing page agent: another turn, another set of prose
boundaries, and a reply that comes back as a notice. In the session behind `docs/suggestions.md` R2 the lead made 81
`page_agent_message` calls and the operator's median request was 404k tokens. S11 passes, so the routing works, but whether
each hop is worth its cost was never measured, and there was no way to run a campaign without the hop to measure it.
Invariant: INV-T4-1, INV-T4-2, INV-T4-3 (added).

## Checked

- `tests/balsamic/test_page_agents_folded.py` (6 tests): under `lead` the lead's commands hold the moderator's and the
  operator's and not the implementation lead's, its tools hold `config_suggest` and `review_synthesis`, `page_agent_message`
  names the other two, its instructions name both procedures and `procedure_read` serves them, `trial.create` is not refused
  as page work while `implementation.commission` is, asking the operator is refused and creates no session,
  `campaign_inspect` lists the folded pages as answered by the lead, and the experiment rules are in its state block. Under
  `standing` the lead's instructions, tools and commands are as before and the procedures are refused. A researcher's
  message on Experiments opens a lead request rooted at the desk, creates no operator, and the reply is on the desk (headed
  by the lead) and not in the chat; the resource planner's desk keeps its agent. A round the lead ran with a reviewer cannot
  end before its synthesis. The switch is refused outside the dev profile, while a request is open, and with another change;
  it changes both ways otherwise. The default comes from `GRATING_PAGE_AGENTS`, and an unknown value is refused.
- Under `standing` the routing tests pass unchanged (`tests/test_page_agents.py`, `tests/balsamic/test_threads.py`,
  `tests/test_roles.py`).
- `scripts/run_lead_evals.py --fake` in both arms: see the PR for the counts. S8 and S11 pass under both settings; S11's
  check names the operator under `standing` (2 runs by it, 1 hand-off) and the lead under `lead` (2 runs by it, no hand-off,
  no operator turn).
- The full Python suite in parallel and the launcher's tests as `claude`: counts in the PR.

## Not done

- **The comparison.** It needs a model, so it is Hoseung's (acceptance test below). Until it runs, `standing` stays the
  default, ADR 0010 is Proposed, and no page agent is folded for good.
- **The fold itself.** Removing a session, its page's routing and its open requests is a new part, added to the roadmap when
  Hoseung accepts ADR 0010.
- The switch cannot be changed from the page: it is a dev-profile command (`agent.configure` with `page_agents`), or the
  environment variable before the team starts.
- The two procedures restate the page agents' instructions in `agents/tools.py` `manifest()`; a change to one must be made in
  the other until the ADR decides which stays.
- J3's partnership rows count a request made on a folded page (it is the lead's), not one made on a standing page agent's
  page (it is the page agent's own). Compare requests made in the chat.

## Acceptance test

1. Start the app in the dev profile with the Centinels provider, from a shell where `GRATING_PAGE_AGENTS=lead` is set. Open a campaign with an installed problem and start the agent team.
2. Open Experiments and open the desk at the bottom. Expected: it is headed "Lead agent" and says the lead agent does the
   experiment operator's work.
3. Write on the desk: "Run two short experiments with an installed method and tell me how they did." Expected: the reply
   comes on the desk, from the lead; two runs appear on Experiments; no experiment operator is started.
4. In the chat, ask: "Review the proposal on Hypotheses with a skeptical domain analyst and a proposal reviewer." Expected:
   Review rounds on Hypotheses shows the round, its synthesis and the verdicts; no discussion moderator is started.
5. Start a second campaign without the variable. Expected: the desks are the experiment operator's and the moderator's, as
   before.

Live eval (Hoseung, Centinels), at this part's commit, two arms of the whole suite, then of the J2 presets:

- Standing: `uv run python scripts/run_lead_evals.py --page-agents standing --repeats 3`
- Folded: `uv run python scripts/run_lead_evals.py --page-agents lead --repeats 3`
- The same two with `--preset deflector_2d` and with `--preset reactor`.

Compare in each run's `summary.md` the passes and the "Page agents" table. ADR 0010's rule: a page agent is folded only if the
`lead` arm passes as many scenarios, with fewer turns or a lower cost, and the lead's largest context stays well within its
model's window (S12, S14 and S16 for the moderator; S8, S11 and the presets for the operator).
