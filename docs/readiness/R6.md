# R6 — From prose to code: who is woken, and the instructions

State: implemented and tested (2026-10-27); the live evals are Hoseung's (acceptance test below).

## What was wrong

Layer: mandate. The outcomes of runs the researcher started directly, work under no mandate of the lead's, woke the lead
and held its request open (Part S's open decision: in S8 the lead answered, then wrote "no change to report" twice), and
the lead's instructions still said in prose what a request allows, which R3's guard now enforces.
Invariant: INV-05 (updated), INV-28 (updated).

## What changed

| Change | Where |
|---|---|
| Outcomes belong to the mandate that started the work. An outcome of work the researcher started directly wakes nobody: the first command or agent receipt that names its record (or the grant or coding workspace it was built under) is a command of the researcher's, such as a run they started from the Evolution page, a `/probe`, or a command they sent. Work a page agent started still wakes that agent; the rest (the lead's work, Balsamic's planned runs, a record no command names) still wakes the lead while a request is open | `agents/controller.py` `researchers()`, `_campaign_events()` |
| The researcher's own runs and jobs no longer hold the lead's request open: `yield_work(complete)` is not refused for them, so a request answered while they run closes with its answer, and nothing is left waiting for an end that now wakes nobody | `agents/tools.py` `outstanding()` |
| The shared instructions drop "Stages (a runtime profile, hypotheses, a review, experiments, a validation, a comparison, findings) are separate: start one only when a request covers it; a request may cover several. Read a request narrowly; say in one line what the broad reading would add." for one line: "Propose the narrowest mandate that answers the request (mandate_propose) and name the broader one in its plan." That is 25 words fewer: the shared core 390 → 365, the lead's instructions 966 → 941. A specialist's instructions do not include the core and stay at 406 | `agents/tools.py` `INSTRUCTIONS` |
| The ratchet goes down: the lead's and the core's limits are lowered to their new sizes (970 → 941, 390 → 365), so growth from here is caught. The recorded sizes `LEAD_WORDS` (886) and `SPECIALIST_WORDS` (389) are already below the current sizes and stay | `tests/test_harness_contract.py` |
| S8's seed starts its two runs with the researcher's own commands, as the pages and the API do, instead of writing the trials directly; the scenario's note says why one answer now closes the request. Its checks are unchanged | `evals/lead/seeds.py` `two_small_runs()`, `evals/lead/scenarios/S8-experiment-status.json` |
| The harness doc says outcomes belong to the mandate that started the work, describes the mandate in place of the prose rule on stages, and links the register | `docs/pi-agent-harness.md` "The lead agent acts on requests" |
| INV-05 states the rule and names its new tests; INV-28 names the lowered limits | `docs/invariants.md` |

`GRANT_INSTRUCTIONS`, the older copy for an implementation grant's roles, keeps its lines: H8 retires it.

## Acceptance test

Start Balsamic with a campaign that has a problem and two proposals with an installed method, and the lead agent switched on.

1. On Evolution, Frontier, select one proposal, press "Allocate time…", enter 60 seconds and a reason, and press Allocate.
   A run starts; Experiments shows it.
2. While it runs, ask the lead in the chat: "How are the experiments going?" It answers once, with what the run shows so far
   and a link to Experiments, and stops: no second message follows.
3. Wait until Experiments shows the run finished. Nothing new appears in the chat: no notice turn of the lead, no "no change
   to report".
4. Type `/probe` in the chat. When the runtime profile has finished (Monitor shows the measured evaluation speed), the lead
   has written nothing.
5. Ask the lead for work of its own: "Run two one-minute probes of coordinate search." It hands them to the experiment
   operator; when both runs end, they wake the operator, its report comes back to the lead, and the lead reports once with
   their numbers. Runs an agent started still wake that agent.
6. Ask: "Create two hypotheses for this problem, each runnable with an installed method. Nothing else for now." The lead
   records two and starts no run; its reply may name the broader work (running them) in one line.
