# P3 — When the quick path holds, and the fall back

State: merged (#113, 2026-10-28), released in `track-p` ([notes](../releases/track-p.md)); not checked live (see the acceptance test).

## What was wrong

Layer: none. Nothing failed: after P2 nothing kept the lead on the quick path from a problem that needed the formulator's
full reading, nothing handed the lead's draft to the formulator when the problem was not simple, and every formulator run
cost one more model call for a reminder to call a tool it does not have.
Invariant: INV-P3-1, INV-P3-2, INV-P3-3, INV-P3-4 (added); INV-P2-4 now says that more questions end the quick path.

## Checked

- `tests/balsamic/test_quick_fallback.py`: each criterion failed (a nondeterministic evaluator, `oracle` access, a fidelity
  field, four variables, eleven inputs, a fourth save with a blocking finding after a warning at the third, three questions,
  a second round) ends the quick path with its reason: the note on the full path, the charter kept and the formulator's, a
  later write refused; questions over the limit are kept unasked and listed in the note to ask. The hand-over writes the note
  from the charter as a lead revision; the gate and the state block say why; `problem_note.confirm` is refused; Adopt gives
  the formulator the same charter, its first prompt names the reason, and its `charter_submit` revises it. Only the researcher
  takes the note to the full path, and not once the charter is confirmed.
- `tests/balsamic/test_quick_charter.py`: a refused write (a question the page could not show as asked) saves nothing.
- `tests/test_problem_import.py`: the formulator's manifest says `extension_host: false`.
- `tests/test_lead_evals.py`: S21 falls back on the scripted harness: four researcher actions (message, Adopt, an answer,
  the confirmation), one lead turn, two formulator turns of one model call each.

## Acceptance test

On a campaign started from the objective only, with the agent team started:

1. In the chat, describe a flow reaction: "We run a flow reaction in a 10 mL tubular reactor at 5 bar. I can set the flow
   rate between 0.1 and 20 mL/min and the temperature between 20 and 200 C. The product decomposes above 150 C. We measure
   the isolated yield by HPLC; it varies between repeats, so each condition is run three times. Find the conditions of
   highest yield. Set the problem up."
2. The lead drafts a charter, then says in one line that the problem needs the full path and why (the yield varies between
   repeats). The Problem note now shows its sections, written from the lead's draft, editable, with Adopt.
3. Adopt it. The Charter tab shows the same charter: the formulator's revision follows the lead's, and you confirm it as
   before.
4. The "Use the full path" button arrives with P5's screens; until then the researcher's own choice of the full path is
   checked by the tests only.
5. Live eval: `uv run python scripts/run_lead_evals.py --scenarios S20,S21`: S20's `quick_path` check reads "held" and
   S21's reads "ended on ... deterministic".
