# I2 — Triage by layer

State: implemented and tested (PR #11, 2026-10-27); no live check needed, the part changes docs and tests only.

## What was wrong

Layer: none. The part fixes no failure of its own; it sets the order in which later failures are triaged.
Invariant: none, it adds no guarantee of Balsamic's: the rule it adds is about how fixes are recorded, checked by its test.

Each incident in the readiness log got a fix on the command it happened on, often a sentence in the agents' instructions,
with nothing to say whether code could have held it instead. The visible failures got code, the silent ones got prose
(design review §06), and no readiness entry said which layer a fix was at or which guarantee it held.

## What changed

| Change | Where |
|---|---|
| The triage page: five layers asked in order (outside the request, over a budget, an unsupported claim or transition, the prompt, the UI), where each is fixed today and which phase takes it over, what every fix adds (a register row and an eval scenario, or why none fits), and six incidents of the readiness log triaged as examples | `docs/incident-triage.md` |
| The readiness format gains `Layer:` and `Invariant:` after "What was wrong", with what each may say | `docs/readiness/README.md` |
| A test checks the two lines wherever a readiness file has them: both present, under "What was wrong" and in order, a layer of the five or `none` with its reason, and only rows the register holds | `tests/test_readiness.py` |
| The register links the triage page | `docs/invariants.md` |

## Checked

- `tests/test_readiness.py`: every readiness file holds (A1, A3 and I1, written before triage, have no lines; this file has
  both); three well-formed fixtures hold, a file without the lines holds, and each of seven broken fixtures fails with its
  own message (an unknown layer, a layer without its reason, a row the register lacks, `none` without why, a lone line,
  the lines in the wrong order, the lines outside "What was wrong").
- `tests/test_invariants.py` still passes.
