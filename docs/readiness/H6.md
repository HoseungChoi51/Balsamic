## What changed

Draft only:

- `agents/library_validation.py` (new): runs the exact commit's library in a bubblewrap sandbox with no network: the
  library's own tests (the generated contract tests among them), `check_function` or `check` per method, and the
  protected acceptance tests kept on the host (`development_protected_test` records). It judges which methods are refused
  and which failures no method owns, and gives the coder protected tests by name and outcome only.
- `agents/library_install.py`: `Installer.install()` validates first; a library-level failure or every method failing
  stops the install; a failing method is left out of `methods_added`, listed in `refused_methods`, and not bound. The coder
  gets a result file and one message; the lead one notice. Validation seconds are charged to the workspace's go-ahead.
- `implementations/builtin.py` `bind()`: refuses a method the latest install refused on the host.
