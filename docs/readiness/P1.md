## Checked

- `tests/test_lead_evals.py`: on the scripted harness, S20 takes today's path in three researcher actions (message, Adopt,
  confirm), three rounds, one lead turn, one formulator turn and one formulator model call, and is graded `xfail` on
  `setup_actions_at_most`; S21 takes four (the charter's question answered too) and two formulator turns, and passes; the
  summary's row. The define step stops on a blocking finding no page settles (an input without a value), after three
  replies to a lead that never writes the note, and at its timeout names what it was waiting for, with no time to the
  charter; the charter checks read the confirmed revision.
- `scripts/run_lead_evals.py --fake`: every other scenario as before; S20 `xfail`, S21 `pass`.
- Full runs at the PR's head: see the PR.

## Not done

- The live baseline (the acceptance test) is Hoseung's: a real run costs money.
- The step's answers are fixed: the recommended option of a charter question, and "use what you suggest" to the lead. A
  live lead that asks for something the message lacks gets that reply, and the transcript shows it.
- The formulator's spend is measured by the runner only; it is still not in `llm_usage`, and its runs still get a
  `yield_work` continuation (P3 sets `extension_host: false` on its manifest).

## Acceptance test

None in the app: the part adds evals. The check is a live run, with the dev profile's default model:

1. In a worktree of the code before track P (`c6c4c32`), build the harness:
   `git worktree add ../balsamic-c6c4c32 c6c4c32 && (cd ../balsamic-c6c4c32/agent-harness && npm ci --ignore-scripts && npm run build)`.
2. From this checkout, run
   `uv run python scripts/run_lead_evals.py --source ../balsamic-c6c4c32 --scenarios S20,S21 --record-baseline`.
3. Read `summary.md`, section "Words to a confirmed charter": for each scenario, the researcher's actions and rounds, the
   lead's and the formulator's turns, model calls, cost and minutes. This is the baseline P6 compares with; commit the
   baseline file the run wrote under `evals/lead/baselines/`.
