# Decision records

Short, dated records of decisions that shape Balsamic, one file each, `NNNN-title.md`, numbered in the order they were
written. Each has a Date, a Status, the Context, the Decision and its Consequences, in about 40 lines at most, and cites
the commit or the document where it was taken. A record is not edited once accepted: a later decision that changes it
is a new record, and the old one's Status says "Superseded by NNNN".

From 2026-10-27 each roadmap decision (`docs/roadmap/README.md` §2) becomes a record here when Hoseung settles it.
